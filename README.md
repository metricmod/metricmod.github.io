# MetricMod

Medição de imagens científicas em uma janela só: área, comprimento, comprimento × largura, contagem,
contagem de colônias, correção de perspectiva, várias fotos e exportação para Excel.

**Abrir / instalar:** https://metricmod.github.io/

- Computador (Chrome ou Edge): abra o link e clique em **Instalar**.
- Android: abra no Chrome e toque em **Instalar**.
- iPhone/iPad: abra no Safari → Compartilhar → **Adicionar à Tela de Início**.

Funciona sem internet depois de aberto uma vez. As fotos e medições ficam no aparelho; nada é enviado.

Os algoritmos de medição seguem os do ImageJ 1.54 (domínio público) e foram conferidos contra ele.
Guia de uso: [LEIA-ME.md](LEIA-ME.md). Código: `codigo-fonte/` (`build.sh` gera o site).
